# North Star Bakery

A responsive multi-page bakery website built as a web development project using HTML, CSS, and JavaScript.

🌐 **Live Demo:** https://davinatech.github.io/school/north-star-bakery/

## About the Project

North Star Bakery is a responsive client-style website designed to provide a warm, approachable browsing experience across desktop and mobile devices.

The project began with HTML structure and was expanded with CSS styling, responsive design, and JavaScript functionality.

## Features

- Responsive multi-page layout
- Navigation across multiple pages
- Product sections
- Contact page
- Audio and video elements
- Mobile-friendly styling
- GitHub Pages deployment
